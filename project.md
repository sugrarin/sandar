## О проекте

SANDAR — это PWA-приложение для тренировки устного счёта. Пользователь выбирает режим и уровень сложности, отвечает на 12 вопросов с 4 вариантами ответа, получает мгновенную обратную связь и видит результат.

Приложение работает без регистрации, но авторизованные пользователи получают полную статистику, историю тренировок, достижения и AI-аналитику прогресса.

**Целевая аудитория:** школьники, студенты, взрослые, которые хотят прокачать скорость счёта в уме.

**Язык интерфейса:** казахский и русский (переключается в шапке).

## Фичи

### Игровой процесс
- **6 режимов:** сложение, вычитание, умножение, деление, таблица умножения, микс
- **4 уровня сложности:** Easy (1 знак) → Medium (2 знака) → Hard (до 3 знаков) → Brain (до 4 знаков); Hard и Brain плавно блендируются с предыдущим уровнем для мягкого разогрева
- **12 вопросов** за раунд, 4 варианта ответа
- **Мгновенная обратная связь:** правильный ответ подсвечивается зелёным, неверный — красным; можно попробовать ещё раз
- **Режим разбора ошибок:** после раунда можно пройти заново только вопросы, на которые ответил неверно
- **Конфетти** при идеальном результате 🎉

### Аккаунт и статистика
- **Вход без пароля** — OTP-код на email (Supabase Auth, SMTP через Resend)
- **Offline-first:** играть можно без аккаунта, сессии копятся в localStorage и синхронизируются при входе
- **XP-система:** за каждый правильный ответ начисляется XP в зависимости от сложности (1–5 XP), бонус +50 XP за каждую 5-ю идеальную сессию подряд; каждые 1000 XP = новый уровень
- **Серии (streak):** счётчик дней подряд и счётчик сессий подряд
- **Тепловая карта активности** в стиле GitHub — 26 недель
- **График точности** по неделям
- **Статистика по режимам** — сколько вопросов и с какой точностью

### Достижения
9 достижений с прогресс-баром и тостом при разблокировке:
- Первая тренировка, 10 тренировок, 100 тренировок
- 100 и 1000 вопросов
- Все режимы (сыграть во все 6)
- Мастер умножения / Мастер деления
- Снайпер (≥ 95% точности суммарно)

### AI-аналитика
- Подключается личный Gemini API-ключ (хранится в профиле)
- Генерирует персональный текстовый разбор прогресса: сильные стороны, что проседает, совет

### Совместный доступ (родитель / учитель)
- Ученик генерирует **код доступа** и делится им
- Родитель или учитель вводит код и получает **доступ только для чтения** к статистике ученика: ответы, ошибки, очки, хитмэп
- Доступ можно отозвать в любой момент

### UX и инфраструктура
- **PWA** — устанавливается на телефон, работает как нативное приложение
- **Light / Dark** тема через `prefers-color-scheme`
- **Mobile-first**, адаптивен до 320px
- **Двуязычный интерфейс** — KZ / RU, переключатель в шапке, locale сохраняется в cookie
- **Error boundary** — при крэше показывает кнопку «Обновить» вместо белого экрана

## Стек

| Слой | Технологии |
|---|---|
| Frontend | Next.js 14 (App Router), React 18, TypeScript, Zustand, CSS (BEM + переменные), Lucide icons |

## Структура проекта

```
app/
  api/
    activity/         # GET тепловой карты
    sessions/         # POST/GET сессий
    stats/            # GET статистики
    share/            # API совместного доступа (code, activate, revoke, student/*)
  globals.css         # Все стили (BEM + CSS переменные)
  layout.tsx          # Root layout

  share/page.tsx      # Публичная страница активации доступа

  GameScreen.tsx      # Вопрос + варианты ответа + прогресс
  HomeScreen.tsx      # Выбор режима и сложности
  ResultScreen.tsx    # Результат раунда + конфетти
  ProfileScreen.tsx   # Статистика пользователя
  ProfileEditScreen.tsx  # Редактирование профиля (имя, аватар, Gemini ключ)
  AiSummaryPanel.tsx  # AI-аналитика на основе Gemini
  Achievements.tsx    # Каталог достижений с прогресс-барами
  AchievementToast.tsx  # Тост при разблокировке достижения
  ActivityHeatmap.tsx # Тепловая карта активности
  AccuracyChart.tsx   # График точности
  SharedAccess.tsx    # Управление совместным доступом (вкладки ученик/родитель)
  StudentStatsView.tsx  # Просмотр статистики ученика родителем
  AuthModal.tsx       # Email + OTP форма входа
  Navbar.tsx          # Шапка с навигацией
  ErrorBoundary.tsx   # Обёртка для recovery при крэше

lib/
  achievements.ts     # Каталог достижений и логика прогресса
  xp.ts               # Расчёт XP и уровней (1000 XP = уровень)
  session.ts          # Сохранение сессий, offline-очередь
  translations.tsx    # Строки интерфейса (KZ + RU)
  ai/                 # Gemini-клиент, промпты, формирование payload

stores/
  gameStore.ts        # Игровое состояние, генерация задач
  statsStore.ts       # Статистика, достижения, активность
  accountStore.ts     # Профиль, совместный доступ
  aiStore.ts          # AI-аналитика

types/index.ts        # Все TypeScript-типы и константы
middleware.ts         # Обновление Supabase-сессии на каждый запрос
schema.sql            # SQL-схема (таблицы, триггеры, RLS)
AGENTS.md             # Правила для AI-ассистентов
```

## Примечания

- Без авторизации всё работает локально (offline-first), сессии копятся в localStorage и синхронизируются при входе (лимит 50 записей)
- XP и streak рассчитываются в триггерах Supabase при вставке сессии
- RLS гарантирует, что каждый видит только свои данные
- Дизайн mobile-first, адаптивен до 320px, максимальная ширина 480px на десктопе
