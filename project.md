# Sandar — Math Trainer

Прогрессивное веб-приложение (PWA) для тренировки устного счёта. Деплоится на `math.timur.ee`.

## Что делает

Тренажёр математики с несколькими режимами, уровнями сложности и системой авторизации. Пользователь выбирает режим, отвечает на 12 вопросов (4 варианта ответа), видит результат, может посмотреть ошибки и повторить.

## Стек

- **Next.js 14.2** (App Router, PPR)
- **React 18** + **TypeScript 5**
- **Zustand 4.5** — клиентский стейт с localStorage-персистентностью
- **Supabase** — авторизация (email/OTP) + PostgreSQL база данных
- **CSS variables** — темизация, dark/light mode, mobile-first

## База данных (Supabase / PostgreSQL)

| Таблица | Назначение |
|---|---|
| `profiles` | Профили пользователей (создаются триггером при регистрации) |
| `sessions` | Раунды: режим, сложность, счёт, длительность |
| `session_answers` | Детали каждого ответа (вопрос, ответ пользователя, правильность, время) |
| `user_stats` | Агрегированная статистика: серия, точность, всего сессий |
| `mode_stats` | Статистика по каждому режиму/сложности |
| `achievements` | Ачивки (задел на будущее) |

RLS включён на всех таблицах — каждый видит только свои данные.

**Триггеры:**
- `on_auth_user_created` → создаёт `profiles` строку
- `on_session_completed` → обновляет `user_stats` и `mode_stats`

## Игровые режимы и логика

**Режимы:** сложение, вычитание, умножение, деление, таблица умножения, микс

**Сложность:**
| Уровень | Диапазоны |
|---|---|
| Easy | 1-значные числа |
| Medium | 2-значные |
| Hard | 3-значные |
| Extreme | 4-значные |

**Раунд:** 12 вопросов, 4 варианта ответа, мгновенная обратная связь.  
**Режим повтора ошибок:** пересдаёт только вопросы, на которые ответил неправильно.

## Авторизация

Email + OTP через Supabase Auth. Гости играют без авторизации, авторизованные пользователи сохраняют историю сессий. Офлайн-сессии хранятся в localStorage и синхронизируются при следующем входе.

## API

| Endpoint | Метод | Описание |
|---|---|---|
| `/api/sessions` | POST | Сохранить сессию |
| `/api/sessions` | GET | Последние 50 сессий |
| `/api/stats` | GET | Статистика пользователя |
